# MizumoriBot 0.6.0-rc1

A Python 1v1 bot with adaptive targeting and wave-aware orbit movement.

Requires Python 3.12 and the official Bot API pinned in requirements.txt. Install dependencies in an environment outside this directory. Use the standard MizumoriBot.sh or MizumoriBot.cmd launcher; RUMBLE_PYTHON may select that interpreter.

Smoke: set RUMBLE_SMOKE=1 before launching. This checks source startup without joining a battle.
